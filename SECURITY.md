# Sikkerhet

RailCAD kjører helt i nettleseren og sender ikke data over nettverket. Det som kan være sikkerhetsrelevant er håndtering av filer som åpnes (prosjektfiler, DXF, PDF, bilder).

Fant du en sårbarhet (f.eks. en fil som får programmet til å henge, bruke uforholdsmessig mye minne eller kjøre kode)? Meld den privat via GitHub: **Security → Report a vulnerability** på repoet. Ikke opprett en offentlig issue for sårbarheter.

Se også `docs/distribusjon.md` (anbefalt CSP) og `NOTICE.md` (ansvarsfraskrivelse).
