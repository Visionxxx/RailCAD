# Utkast: henvendelse om sporvekseltegninger (KO)

**Til:** Bane NOR – Teknisk dokumentasjon / ProArc-ansvarlig
**Emne:** Forespørsel om KO-tegninger og geometridata for sporveksler til CAD-/prosjekteringsverktøy

Hei,

Vi utvikler et parametrisk 2D-CAD-program for prosjektering av sporplaner (verksteder, hensettingsanlegg, terminaler). Vi bruker i dag hovedmålene (A, B, C, D, L, E, F) fra TRV Overbygning/Prosjektering/Sporveksler (utgitt 18. mai 2026, oldid 141902) og har avledet akser fra dem. Vi markerer disse som **delvis verifisert**, og ønsker underlag for å kunne verifisere dem.

**Vi ber om følgende for tegningene:**

| Tegning   | Type                             |
| --------- | -------------------------------- |
| KO-701409 | 60E1 1:9 R300, fast kryss (EVF)  |
| KO-800068 | 60E1 1:12 R500, fast kryss (EVF) |
| KO-701334 | 54E3 1:9 R190, kort kurve        |

1. Tegningene i DWG/DXF, eller PDF hvis CAD ikke er mulig, med revisjon.
2. For stamspor og avvikende spor: koordinater (eller mål) for stokkskinneskjøt (SS), tungespiss, teoretisk kryss (TK), sirkelkurvens endepunkt (R2) og skjøtene i bakkant (BK).
3. Bekreftelse av definisjonene i tegnforklaringen:
   - Måles C og D langs avviksbuens tangent, eller i X-retning (stamsporets retning)?
   - Ender avvikssporets midtlinje på R2 + D langs tangenten, eller på bakkantlinjen (BK)?
4. Vilkår for å bruke geometrien i programvare og for å distribuere den i et versjonert objektbibliotek (med kilde og revisjon).

Oppgi gjerne dokumentrevisjon og dato slik at vi kan versjonere biblioteket sporbart.
