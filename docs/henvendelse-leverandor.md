# Draft: request to turnout/crossing suppliers

**To:** Vossloh Cogifer (sales / engineering) and voestalpine Turnout Technology (sales / engineering)
**Subject:** Request for geometry data for crossings, diamond crossings and double slips – CAD/track-design software

Hello,

We are developing a parametric 2D CAD tool for railway track layouts (workshops, stabling yards, terminals), initially for the Norwegian market (Bane NOR). We want to include a versioned library of turnouts and crossings with **verified geometry**, and we would like to ask whether you can provide data for the following, in DXF/DWG or table form:

1. **Diamond crossings (single and double) and double slips / crossing switches** for UIC60 (60E1) and UIC54 (54E3) rails, crossing angles 1:9 and 1:12 (and any other standard angles you supply), including radii.
2. For each type: centre-line coordinates (or main dimensions) of the theoretical crossing point, tongue/switch tips, crossing noses, joints and the ends of the layout, plus drawing number and revision.
3. Applicable **limits**: allowed crossing angles, required straight lengths before/after a crossing, minimum distance to adjacent turnouts or curves.
4. Any existing catalogue data files (CAD blocks, "layout libraries") that you share with design offices.
5. The **terms** under which the geometry may be used and redistributed in software (with source and revision attribution).

For reference, Bane NOR's TRV lists drawing numbers KO-068394, KO-800167 (double slips 1:9 R190), KO-066249 and KO-066250 (double loops with crossing, 4700 mm track spacing). If these are your products, we would gladly refer to your own drawing numbers instead.

Please tell us the revision and date of the data so we can version the library traceably. Until verified data is available we mark all such objects as "partially verified / not for approved design".
